**Группа:** 251-951

## Вариант заданий

### Задание 1. Dockerfile
Написать Dockerfile на базе образа Ubuntu 18.04: разместить информацию об авторе
в виде комментария, установить компилятор gcc, скопировать файлы проекта в папку
`MyProj_251-951_Dalakov`, скомпилировать проект в файл `my_Program`, задать значение
параметра программы по умолчанию и запустить программу с параметром. Написать команды
для сборки образа, публикации на DockerHub (или зеркале) в открытом доступе и запуска.

### Задание 2. Класс MeticRegister (паттерн Singleton)
На основе паттерна Singleton написать класс `MeticRegister` — реестр метрик.
Первичные метрики хранятся в ассоциативном массиве: ключ — момент времени (целое число),
значение — пара <время отклика; время ожидания>. Реализовать методы:
- `bool add_metr(int resp_t, int wait_t)` — добавление метрики;
- `bool show_mert()` — вывод всех значений, упорядоченных по ключу;
- `int coutn_cometr(int key)` — сумма времени ожидания и отклика для данного ключа.

Для демонстрации — консольное приложение без Qt. Написать UnitTest для одного из
методов класса на 10 различных входных значениях.

## Структура репозитория
- `docker/` — `Dockerfile` и исходник `main.c` (Задание 1)
- `meticregister/` — исходники C++ (Задание 2)

Скрины работы программы, докера и работы с репозиторием находятся в ветке `screens`.
